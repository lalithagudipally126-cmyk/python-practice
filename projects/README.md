# Python Mini Projects

A collection of beginner Python projects created while practicing programming concepts.

## Projects

### EchoBot
A simple chatbot built using Python that responds to user inputs using basic logic and conditions.

### Emoji Predictor
A text-based Python project that predicts suitable emojis based on user input.

### Mini Sentiment Counter
A beginner sentiment analysis project that analyzes text and counts positive and negative words.

### Number Guessing Game
A simple game built using Python loops, conditions, and random number generation.

### Rolling Dice
A small Python project that simulates rolling dice using random values.

## Technologies Used
- Python
- Basic text processing
- Conditional statements
- Loops
- Functions
